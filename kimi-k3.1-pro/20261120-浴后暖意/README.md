# 浴后·暖意

- **模型**：Kimi K3.1 Pro（Kimi Agent）
- **日期**：2026-11-20
- **题目**：无来头跑分——「兽人浴后擦拭身体的动画」。非露骨，腰间浴巾全程遮挡。
- **成片**：`D3_浴后暖意_整片预览.mp4`（8 秒，1920×1080，24fps，192 帧，h264）

## 是什么

一只叫「岚」的成年狼兽人洗完澡，拿毛巾擦干自己：取巾 → 覆头揉擦 → 擦肩背 →
甩水抛滴 → 抖毛 → 补擦 → 松弛定格，九个节拍一气呵成。

技术路线相当扎实：不是逐帧画图，而是一份**参数化矢量动画源**
（`D1_矢量动画源.txt`，实为可直接执行的 Python），所有动画通道仅由时间 `t`
驱动，固定随机种子 `SEED = 20261120`，逐帧生成 SVG 再栅格化，ffmpeg 合成视频。
同一环境重跑逐字节可复现（D5 里有验证记录：抽 6 帧重渲染，SVG 逐字节一致、
PNG 逐像素一致）。手臂用双段 IK，毛巾是同一路径的连续形变，水滴有重力下落、
切线抛射和落地涟漪——细节讲究到有点过分。
