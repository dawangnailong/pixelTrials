## 二、环境依赖

本次实际验证环境：

- Python 3.12.12
- CairoSVG 2.9.1
- Pillow 13.0.0
- FFmpeg 5.1.9（兼容的更新版本亦可）

Python 依赖安装：

```bash
python3 -m pip install cairosvg==2.9.1 pillow==13.0.0
```

视频编码需要系统可执行文件 `ffmpeg`；参数核对可选装 `ffprobe`（通常随 FFmpeg 一起提供）。动画不使用外部图片、第三方角色资产或网络资源。

## 三、一键完整重跑

在交付目录执行：

```bash
cd "/mnt/agents/output/浴后暖意_交付"
python3 D1_矢量动画源.txt --video --out "./重渲染输出"
```

该命令会依次完成：

1. 按 `scene(n / 24)` 生成 192 张分层 SVG；
2. 栅格化为 192 张 1920×1080 PNG；
3. 导出 9 张节拍关键帧与关键帧总览；
4. 以 24fps 编码完整 8 秒 MP4。

如需保留本次最终渲染日志的同一调用形式：

```bash
cd "/mnt/agents/output/浴后暖意_交付"
python3 D1_矢量动画源.txt \
  --video \
  --out "/mnt/agents/output/浴后暖意_交付" \
  > "/mnt/agents/output/浴后暖意_交付/最终渲染日志.txt" 2>&1
```

注意：第二条命令会覆盖交付目录中的同名帧序列、关键帧与 MP4；需要保留现版时请使用第一条命令输出到 `./重渲染输出`。

## 五、常用参数

### 只渲染指定帧

```bash
python3 D1_矢量动画源.txt \
  --frames 0,36,74,113,162,191 \
  --out "./抽帧输出"
```

帧号使用逗号分隔，不填 `--frames` 时默认渲染全部 192 帧。

### 只渲染 9 个节拍关键帧

```bash
python3 D1_矢量动画源.txt \
  --keyframes-only \
  --out "./关键帧输出"
```

此模式同时生成 `D2_关键帧/` 与 `D2_关键帧总览.png`，不编码视频。

### 低分辨率测试

```bash
python3 D1_矢量动画源.txt \
  --frames 0,36,113,180 \
  --scale 0.5 \
  --out "./半尺寸测试"
```

`--scale 0.5` 输出 960×540；正式交付必须保持默认 `--scale 1.0`。

## 六、源文件调参入口

- `W, H, FPS, DURATION`：宽度、高度、帧率、时长。
- `SEED`：水滴、蒸汽等细节的确定性随机种子。
- `BEATS`：9 个节拍节点及关键帧导出名称。
- `P`：统一色板。
- `scene(t)`：唯一场景时间入口与显式图层顺序。
- `smooth()`、`keys()`：缓动与时间关键帧插值。
- `ik()`、`limb()`：手臂双段 IK 与连续肢体轮廓。
- `head()`、`generic_towel()`：头部挤压与同一毛巾的连续路径形变。
- `water_drops()`：重力下落、切线抛射、地面求交与落地涟漪。

所有动画通道仅由 `t` 驱动；同一参数与依赖版本下可重复生成相同结果。

## 七、结果核对命令

### 视频参数

```bash
ffprobe -v error \
  -select_streams v:0 \
  -show_entries stream=codec_name,width,height,pix_fmt,r_frame_rate,duration,nb_frames \
  -of json \
  "./重渲染输出/D3_浴后暖意_整片预览.mp4"
```

预期核心值：`h264`、`1920×1080`、`yuv420p`、`24/1`、`8.000000`、`192`。

### 完整解码检查

```bash
ffmpeg -v error \
  -i "./重渲染输出/D3_浴后暖意_整片预览.mp4" \
  -f null -
```

无错误输出且返回码为 0，即完整解码通过。
