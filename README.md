# pixelTrials

存放 AI「跑分」产出的前端动画设计例子。

所谓跑分：在没有正经任务的时候，丢给 AI 一个毫无来头的前端动画设计题目
（「画一个会呼吸的星空」「做个像素风瀑布」之类），看它发挥成什么样。
做得好的、想留下来的，收进这个仓库。

## 目录结构

按 **模型 → 主题** 两级分小类子项目，每个试验是一个自包含的小目录：

```
pixelTrials/
├── README.md
├── .gitignore
└── <model>/                 # 按模型分，如 glm-5.3/
    └── <yyyymmdd>-<theme>/  # 一次试验 = 一个子项目，如 20261121-breathing-starfield/
        ├── index.html       # 打开即看，尽量单文件、零构建
        └── README.md        # 题目原文 + 当时的 prompt + 简短点评（可选）
```

## 约定

- 试验目录名带日期前缀，避免重名，也方便按时间浏览。
- 单个试验尽量 `index.html` 一个文件搞定（内联 CSS/JS），不用构建工具。
- 若某个试验确实需要 npm 依赖，自行加 lockfile 并提交，`node_modules/` 已在 gitignore。
- 想保存就提交，不想保存的直接删，不纠结。

## 收录标准

只有一条：觉得值得再看一眼的才放进来。
